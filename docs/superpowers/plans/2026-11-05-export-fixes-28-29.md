# Export Fixes (#28 and #29) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the `body stream is locked` TypeError during CSV export downloads on `/settings/export` (Issue #28) and add human-readable activity and category names to CSV and JSON/Full Backup exports on `/settings/mood-log-tools` (Issue #29) while preserving database IDs for safe backup restoration.

**Architecture:** 
1. Fix client-side response stream consumption in `settings/export/+page.svelte` by reading chunks to completion whenever a reader is acquired, and forward `content-length` and `content-disposition` through SvelteKit's API proxy (`api/[...path]/+server.ts`).
2. Build activity-to-name and activity-to-category lookup maps in `settings/mood-log-tools/+page.svelte` using the already loaded `activities` and `categories` state, enriching CSV rows and JSON backup entries with human-readable names alongside IDs.
3. Verify backward compatibility with the import/restore tool in `mood-log-tools`.

**Tech Stack:** Svelte 5 / SvelteKit, TypeScript, FastAPI backend.

---

### Task 1: Fix stream consumption and proxy headers for `/settings/export` (Issue #28)

**Files:**
- Modify: `frontend-web/src/routes/api/[...path]/+server.ts`
- Modify: `frontend-web/src/routes/settings/export/+page.svelte`

**Steps:**
- [ ] In `frontend-web/src/routes/api/[...path]/+server.ts`, forward `content-length` and `content-disposition` headers from upstream backend response so browser downloads receive proper metadata.
- [ ] In `frontend-web/src/routes/settings/export/+page.svelte`, fix `exportCsv()`:
  - If `response.body?.getReader()` is called, read from the reader until `done: true` regardless of `totalBytes`, and construct the Blob from `chunks`.
  - Only update progress percentage if `totalBytes > 0`.
  - If no reader or stream is unsupported, fall back to `await response.blob()`. Never call `await response.blob()` after `getReader()` has been called.
- [ ] Run `npm run check` in `frontend-web` to verify types.
